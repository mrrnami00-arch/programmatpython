# 💻 خدمات متلب و برنامه‌نویسی

وب‌سایت معرفی خدمات برنامه‌نویسی، شبیه‌سازی، ترجمه علمی و طراحی با بیش از ۱۵ سال سابقه.

🌐 **آدرس سایت:** [www.programmatpython.ir](https://www.programmatpython.ir/)

---

## 📌 درباره پروژه

این مخزن شامل سورس صفحه اصلی (Landing Page) وب‌سایت خدمات متلب و برنامه‌نویسی است. سایت به‌صورت **تک‌صفحه‌ای، ایستا (Static)** و بدون نیاز به بک‌اند یا ابزار ساخت (Build) نوشته شده و فقط از HTML و CSS خالص استفاده می‌کند.

## ✨ ویژگی‌ها

- 🇮🇷 **راست‌به‌چپ (RTL)** و بهینه برای زبان فارسی (`lang="fa" dir="rtl"`)
- 📱 **ریسپانسیو** با CSS Grid و Media Query برای موبایل، تبلت و دسکتاپ
- 🔍 **بهینه برای سئو:** متای توضیحات، Canonical، Open Graph، Twitter Card و داده ساختاریافته Schema.org (`ProfessionalService`)
- ⚡ **سبک و سریع:** بدون فریم‌ورک؛ بارگذاری غیرمسدودکننده Font Awesome و Lazy Loading تصاویر
- ♿ **دسترس‌پذیری:** استایل `focus-visible`، `aria-label` برای دکمه‌ها و پشتیبانی از `prefers-reduced-motion`
- 📊 **آنالیتیکس:** یکپارچه با Google Analytics (gtag.js)

## 🚀 اجرا و استقرار

### اجرای محلی

```bash
git clone https://github.com/<USERNAME>/<REPO>.git
cd <REPO>
```

سپس فایل `index.html` را در مرورگر باز کنید. یا برای اجرای یک سرور محلی:

```bash
python -m http.server 8000
# سپس به http://localhost:8000 بروید
```

### استقرار روی GitHub Pages

1. به **Settings ← Pages** مخزن بروید.
2. در بخش **Source**، شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
3. پس از چند دقیقه سایت در آدرس `https://<USERNAME>.github.io/<REPO>/` در دسترس است.

برای استفاده از دامنه اختصاصی، فایلی با نام `CNAME` حاوی `www.programmatpython.ir` به ریشه پروژه اضافه کنید.
